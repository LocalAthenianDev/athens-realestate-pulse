# Ανάλυση δεδομένων

Αναπαράγει τα νούμερα του εγγράφου ανάλυσης για το business plan.

```bash
pip install pandas numpy scikit-learn
python3 analysis/fetch_history.py   # κατεβάζει όλο το ιστορικό στο analysis/data/
python3 analysis/analyze.py         # ποιότητα, κατατάξεις, εποχικότητα, τάσεις, τύποι περιοχών
```

Οι κανόνες ποιότητας είναι ίδιοι με αυτούς του server (`lib/aggregate.js`):

- αθροιστική κίνηση έγκυρη όταν είναι > 0 και τουλάχιστον 15 φορές η κορυφή της ίδιας ημέρας
- ταυτόχρονη παρουσία έγκυρη από 8/7/2026, όταν είναι τουλάχιστον 0,25 φορές η κορυφή
- κορυφή έγκυρη όταν είναι > 0 και έως 4 φορές η διάμεση τιμή του σταθμού

Έτσι εξαιρούνται τα κενά του Ιανουαρίου και του Φεβρουαρίου 2026 και η περίοδος 31/3 έως 7/7/2026, όταν το API δημοσίευε σε άλλη κλίμακα.
